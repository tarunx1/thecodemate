# Card photo sources

These are decorative stock photographs for cards without an uploaded CMS cover. They do not depict the named project's actual UI or prove a topic's content. A CMS cover always takes priority. The files are stored locally so the public site does not request Unsplash at runtime.

The photographs were downloaded from `images.unsplash.com` on 2026-11-12 at 960 × 1200 pixels. The [Unsplash License](https://unsplash.com/license) allows use on the site; attribution is appreciated but not required. Image content has natural photographic colors, while interface surfaces and typography continue to use the five brand colors.
